# 흥얼 hum — 가족끼리 노래 주고받기

모바일용 프로토타입 (HTML 한 파일, 빌드 없음). `python3 -m http.server` 후 `/family-songs/` 를 폰 브라우저로 열면 됩니다.

## 화면
- **홈** — 도착한 노래 캐러셀(스크롤하면 기울고 블롭이 패럴랙스), 우리집 타임라인
- **보내기(+)** — 제목/아티스트/링크 → 받는 사람 → 무드 그래프(점을 드래그, 파란 글로우 선이 따라옴) → 한 줄 메모 → **꾹 눌러서 보내기** (블롭이 날아감)
- **플레이어** — 클릭휠을 돌리면 탐색, 위=답장 / 좌우=이전·다음 / 아래=재생. 무드로 만든 허밍(WebAudio)이 재생되고 '원곡 찾아 듣기'로 유튜브/링크 연결. 리액션 이모지, 하트.
- **가족** — 공전하는 가족 별자리(주고받은 만큼 선이 굵어짐), 멤버 카드, 이번 주 가족 무드. **"○○ 시점으로 앱 보기"** 로 다른 가족 입장에서 받은 노래를 확인할 수 있어요.

## 무드 → 색
4개 축(차분한↔신나는, 먹먹한↔행복한, 새벽↔한낮, 혼자↔함께)이 블롭 색 4개를 결정합니다. 같은 노래도 보내는 마음에 따라 다른 모양·색이 됩니다.
