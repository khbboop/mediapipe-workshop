# 08 — ECHO NOD car screen

A clickable prototype of the ECHO NOD in-car screen (2.2 : 1), built from the team's screen designs.
Only the screen is shown. The sound-bloom jelly (example 07) runs as a soft background light behind the player,
tinted with the color of whoever picked the song.

Flow: start logo → 탑승 인식 (ON BOARD) → 탑승이 확인됐어요 → 오늘 함께하는 사람 → 플레이리스트 조합 (CREW SHARE)
→ 재생 (NOW PLAYING) → 도착 기록 (ARRIVAL). During the ride, family events show up on their own:
엄마's like arrives during NEON, and 올언니's song (야경) arrives during DADZ LOVE as a small card: + puts it next in the queue, 확인 just acknowledges it.
Player screens use the SONG SHARE label; each song's progress bar takes its cover color.

On screen: tap to start, tap a person to confirm boarding, play/pause/prev/next, tap a song in the stack,
♥ to like, the paper-plane icon to send the song to family, back and home in the top bar.

Presenter keys (`H` shows them): Space play/pause · ←/→ songs · `L` like arrives · `R` song arrives ·
`N` "이 노래 별로야" (FAMILY MIX) · `S` send a song · `E` arrive · `0` back to start.
Drop an audio file on the page to drive the light with it. Covers are abstract placeholders; song titles are example data.
