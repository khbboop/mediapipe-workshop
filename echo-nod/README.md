# ECHO NOD — 모바일 앱 프로토타입

가족이 같은 차에서 서로의 노래를 듣다가 말이 트이는 서비스, ECHO NOD의 모바일 앱 프로토타입이에요.
브리프는 [`reference/ECHO_NOD_brief.md`](reference/ECHO_NOD_brief.md)에 있어요.

## 실행

카메라는 필요 없지만, ES 모듈 때문에 로컬 서버로 열어야 해요.

```bash
# 저장소 루트에서
python3 -m http.server 8000
```

- 앱: <http://localhost:8000/echo-nod/>
- 캐릭터 여섯 명 라인업: <http://localhost:8000/echo-nod/lineup.html> (캐릭터를 누르면 끄덕 → 도리도리 → 폴짝 → 흔들)

Three.js는 `vendor/`에 들어 있어서 인터넷이 없어도 돌아가요 (글꼴만 Google Fonts에서 받아요).

### 유용한 주소 옵션

| 주소 | 하는 일 |
|---|---|
| `?reset` | 저장된 상태를 지우고 처음 실행처럼 시작 (인트로 → 처음 설정) |
| `#home`, `#received/r1`, `#send/dad`, `#between/mom`, `#family`, `#me`, `#setup` | 인트로를 건너뛰고 바로 그 화면으로 |
| `?lite` | 털 겹 수를 줄여서 느린 폰에서도 부드럽게 |

## 화면

| # | 화면 | 주인공 | 주인 색 |
|---|---|---|---|
| 0 | 인트로 | 내 캐릭터 → 가족 색 번짐 | 크림 |
| 1 | 처음 설정 (가족 · 캐릭터 · 부르는 말 · 차 표시) | 고르는 캐릭터 | 그 캐릭터 색 |
| 2 | 홈 | 나 (크게, 받침 카드 위로 솟음) + 가족 (작게, 상태를 동작으로) | 내 색 |
| 3 | 받은 노래 | 보낸 사람이 곡 카드 위에 걸쳐 섬 | 보낸 사람 색 |
| 4 | 노래 보내기 | 받을 사람 | 받을 사람 색 |
| 5 | 그 사람과 나 사이 | 그 사람 (크게) + 나 (작게), 뒤에 두 색이 섞인 정도 | 그 사람 색 |
| 6 | 우리 가족의 노래 | 가족 색이 섞인 큰 번짐, 곡은 주석처럼 | 섞인 색 |
| 7 | 나 | 내 캐릭터를 표본처럼, 설정은 도감 주석처럼 | 내 색 |

홈에서 가족 캐릭터는 상태를 동작으로 보여 줘요.

- 물결 + 꼼지락: 나에게 노래를 보냄 → 누르면 **받은 노래**
- 의자에 앉아 있음: 지금 차에 타고 있음 → 누르면 **노래 보내기** (바로 차에서 나옴)
- 끄덕 / 도리도리를 반복: 내가 보낸 노래에 답이 옴 → 누르면 **그 사람과 나 사이**
- 가만히 있음 → **그 사람과 나 사이**

## 구조

```
echo-nod/
├── index.html            앱 진입점 (importmap으로 vendor/three 연결)
├── lineup.html           캐릭터 여섯 명 확인용 페이지
├── css/app.css           디자인 규칙 (큰 주인공 · 작은 글자 · 한 색 명도 · 버튼 강조 하나)
├── js/
│   ├── fur.js            셸(shell) 털 셰이더 + 파라메트릭 몸통 지오메트리
│   ├── characters.js     캐릭터 여섯 명 모델 + 동작(끄덕 · 도리도리 · 폴짝 · 깜빡임 · 숨쉬기)
│   ├── stage.js          WebGL 캔버스 하나를 앱 위에 깔고, 화면의 빈 슬롯마다 캐릭터를 그림
│   ├── color.js          화면 주인 색 하나로 배경 · 카드 · 버튼 톤을 만듦
│   ├── data.js           가짜 가족 · 곡 · 주고받은 기록 (localStorage에 저장)
│   ├── audio.js          실제 음원 대신, 곡마다 다른 잔잔한 화음
│   ├── ui.js             DOM 도우미 (번짐, 물결, 가는 연결선, 시트 …)
│   ├── main.js           라우터
│   └── screens/          0~7번 화면
├── vendor/               three.js r170 (MIT)
└── reference/            브리프와 캐릭터 시트
```

### 털은 어떻게 그리나

몸 표면을 수십 겹(셸)으로 조금씩 부풀려 반복해서 그리고, 털 가닥 높이 텍스처로 각 겹에서 털이 닿는 곳만 남겨요.
뿌리는 어둡게, 끝과 가장자리는 밝게(림 라이트) 처리해서 보송한 질감을 내요.
주인공은 26~30겹, 작은 캐릭터는 12~14겹으로 그려서 폰에서도 부담이 적어요.

## 프로토타입이라 하지 않는 것

- 실제 음악 서비스 연결, 실제 재생 (곡마다 만든 소리로 대신해요)
- 실제 가족 계정 · 초대 · 알림, 실제 차량 연동
